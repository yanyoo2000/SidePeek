# SidePeek 使用说明

> 一句话：**在 B 站想看某个视频，不用离开当前页面 —— 点一下，视频从右边滑出来；关掉，原来的页面还在原地。**

本文面向所有用户，不需要懂技术。每一步都写清"点哪里、看到什么"。

## 1. 这是什么

刷 B 站时最常见的浪费：点开一个视频，发现不想看，退回来 —— 首页推荐流已经重排了，刚才看到第几屏忘了；或者搜东西时点开一个结果，回来发现筛选条件丢了。

SidePeek 改变的是**"点开视频"这个动作**：

- 平时点视频 → 整个页面跳走，当前页面没了。
- 装了 SidePeek 后点视频 → 右边滑出一个抽屉，抽屉里是完整的视频页；左边你原来的页面**一格都没动**。
- 看完了点右上角 × 关掉抽屉 → 回到原来的页面，滚动条位置、搜索结果、筛选条件都还在。

抽屉里不是缩水版播放器，就是 B 站真正的视频页：**能播放、有弹幕、有评论区、有右侧推荐**。

## 2. 安装（约 1 分钟）

> 需要 **Chrome 102 或更高版本**（检查方式：Chrome 右上角三个点 →「设置」→ 左侧最下面「关于 Chrome」，能看到版本号）。
> 安装不需要懂命令、不需要安装别的东西。

### 第 1 步：把文件下载到电脑上

打开项目地址 <https://github.com/yanyoo2000/SidePeek> ：

- 点页面右侧绿色的 **「Code」** 按钮 → 选 **「Download ZIP」**；
- 下载完成后解压，得到一个文件夹（名字通常是 `SidePeek-main`）。

把这个文件夹放到一个**长期不会删的地方**（比如"文档"文件夹里）。⚠️ **扩展是直接从文件夹读取的，装好之后请不要删除或移动这个文件夹**，否则扩展会失效。

### 第 2 步：打开扩展管理页

在 Chrome 地址栏输入下面这行，然后回车：

```
chrome://extensions
```

→ 你会看到一个"扩展程序"页面（里面可能已经有别的扩展）。

### 第 3 步：打开右上角的「开发者模式」

→ 页面**右上角**有一个「开发者模式」开关，把它拨到**开启**。
→ 开启后，左上角会多出三个按钮，其中一个是 **「加载已解压的扩展程序」**。

### 第 4 步：选择文件夹

→ 点 **「加载已解压的扩展程序」** → 弹出选择文件夹的窗口。
→ 选中刚才解压出来的那个文件夹（`SidePeek-main` 或你 `git clone` 得到的 `SidePeek`），点「选择文件夹」。

⚠️ 这里最容易出错：要选的是**里面能直接看到 `manifest.json` 文件的那一层**。判断方法：打开这个文件夹，第一眼就能看到 `manifest.json`、`src` 文件夹、`icons` 文件夹 —— 就是这个。不要选它的上一级（比如你解压到了 `下载\SidePeek-main\`，那就选 `SidePeek-main`，不要再往上选一层）。

→ 选对之后，扩展列表里会出现一张 **SidePeek** 卡片，上面写着版本号 `0.1.0`，没有红色报错。

### 装好了，最后做一件事

**打开（或切换到）一个 B 站页面，按一次 `F5` 刷新。**
扩展只在页面加载时装进去，安装之前就已经开着的 B 站标签页需要刷新一次才会生效。

可选：点 Chrome 工具栏右侧的**拼图图标 🧩** → 在列表里找到 **SidePeek** → 点它右边的**图钉**，图标就会常驻工具栏（点这个图标不会有弹窗，见 FAQ 第 12 条）。

### 怎么确认真的装好了

打开 B 站首页，**单击**任意一个视频的封面或标题：

- ✅ 页面没有跳走，右侧滑出一个深色抽屉，抽屉顶部显示视频标题 —— 成功。
- ❌ 整个页面跳到了视频页 —— 没生效，请回到本文第 2 步，确认扩展已加载并已刷新页面。

## 3. 第一次使用：三个入口

### 入口一：首页刷推荐

1. 打开 <https://www.bilibili.com/>，让首页推荐流刷出来。
2. **单击**任意一个视频卡片（封面或标题都行）。
3. → 约 0.3 秒后，深色抽屉从右侧滑出：
   - 顶部一行：**视频标题** + 右侧三个按钮（↗ 在新标签页打开 / 复制链接 / × 关闭）；
   - 内容区：先是黑的，随后出现 B 站视频页；
   - 内容区最上方会有一条**蓝色细线左右扫动**，表示正在加载；加载完它就消失。
4. → 在抽屉里点播放键看视频。看完点右上角 **×**。
5. → 抽屉滑回右侧消失，**首页还是刚才那一屏，滚动位置一点没变**。

### 入口二：搜索结果里快速比对

1. 在 B 站搜索任意关键词，进入搜索结果页（地址栏是 `search.bilibili.com`）。
2. **单击**第一个结果的视频标题。
3. → 抽屉滑出，视频在右侧播放，**左侧搜索结果页完全没动**（关键词、页码、筛选都还在）。
4. → 不感兴趣？直接在左边再点第二个结果 —— 抽屉保持展开，只换内容，**不会再"重播"一次滑入动画**。
5. → 连看三个之后点 ×，回到搜索结果页继续挑。

> 这一步是 SidePeek 技术上最关键的场景：搜索页和视频页属于不同站点，普通做法会被 B 站"把整页顶走"。SidePeek 能稳定压住（原理见 README 的「它是怎么做到的」）。

### 入口三：看视频时瞄一眼相关推荐

1. 正常点开一个视频，看了一会儿。
2. 在右侧「相关推荐 / 接下来播放」里，**单击**另一个视频标题。
3. → 当前视频页**不会被替换**：抽屉从右边滑出，里面是新视频。
4. → 觉得还是原来那个好？点 × 或按 Esc 关掉抽屉，原来的视频页还在，播放进度也在。

## 4. 完整操作手册

### 4.1 打开抽屉

**点哪里**：B 站页面里任意视频链接（首页卡片、搜索结果的标题、右侧相关推荐、分区列表里的视频……）。
**看到什么**：右侧滑出深色抽屉，顶部显示标题，内容区加载 B 站视频页。

这几种情况**不会**打开抽屉，而是按浏览器的正常方式跳转：

| 你做了什么 | 结果 | 原因 |
|---|---|---|
| 按住 `Ctrl` / `⌘` / `Shift` / `Alt` 再点 | 正常在新标签打开 | 这是你明确要"新标签"，扩展不抢 |
| 用**鼠标中键**点 | 正常在后台新标签打开 | 同上 |
| 点的**不是视频**（动态、专栏、用户主页、番剧索引页等） | 正常跳转 | 只接管视频页 |
| 点的视频**就是你当前正在看的这个** | 正常跳转 | 避免抽屉里套抽屉 |
| 原页面正在**全屏播放**（按过播放器的全屏） | 正常跳转 | 全屏时抽屉无法显示在最上层，所以不接管 |
| 点的是卡片上的**小按钮**（如"稍后再看"、点赞） | 按钮正常工作 | 不打断 B 站自己的功能 |

### 4.2 在抽屉里看视频

抽屉里是**完整的 B 站视频页**，跟你平时看到的一样：

- **播放**：点一下画面中间的播放键。视频**不会自动播放**（浏览器限制，所有网站都一样）。
- **弹幕**：正常显示。开关在播放器下方的弹幕按钮上，行为和正常页面一致。
- **清晰度 / 倍速**：在播放器右下角的设置里，和正常页面一致。
- **评论区**：在抽屉里往下滚就能看到（滚动的是抽屉里的内容，不是左边页面）。
- **登录相关**（发弹幕、发评论、投币）：需要你已经在 B 站登录。如果抽屉里提示未登录或发送不了，点右上角 **↗** 用新标签页打开这个视频，在正常页面里操作。

### 4.3 换一个视频

**点哪里**：抽屉开着的时候，直接在左边页面再点另一个视频链接。
**看到什么**：抽屉**不动**，内容区换成了新的视频（顶部标题也跟着换）。入场动画**不会重播**。

> 小提示：正常速度点击没问题。如果手特别快，在一瞬间连点好几个视频，可能会看到内容区闪几下（已知限制第 7 条）。

### 4.4 关闭抽屉（四种方式）

| 方式 | 点哪里 | 看到什么 |
|---|---|---|
| 关闭按钮 | 抽屉右上角的 **×** | 抽屉滑回右侧消失 |
| 键盘 | 按 **Esc** | 同上（**前提**：焦点还没进到抽屉里的视频区域，见 4.10） |
| 点外面 | 点抽屉**左侧变暗的页面区域** | 同上 |
| 浏览器后退 | 点浏览器的 ← 后退按钮 / 按 `Alt`+`←` | 同上，而且**不会**离开当前页面 |

关闭后：抽屉里的视频会**停止**（约 0.4 秒内静音），原页面恢复原样。

### 4.5 用「前进」重新打开

**点哪里**：刚刚关掉抽屉后，点浏览器的 → **前进**按钮。
**看到什么**：抽屉按刚才那个视频重新打开（会重新加载一次）。

这是刻意做的：打开抽屉相当于浏览历史里的"一步"，所以后退=关、前进=开，符合直觉。

### 4.6 调整抽屉宽度

1. **点哪里**：把鼠标移到抽屉的**最左边缘**（细窄的一条，鼠标会变成左右箭头 ⇔），左边缘会出现一条**蓝色细线**。
2. 按住鼠标左键，**向左拖变宽 / 向右拖变窄**，松手。
3. **看到什么**：抽屉宽度实时跟着鼠标走；松手后宽度固定下来。
4. **下次还会是这个宽度**：宽度记在你这台电脑上（重开抽屉、刷新页面、重启浏览器都记得）。
   - 不会跟着账号同步到别的电脑。
   - 抽屉**最宽**不会超过屏幕的 90%，左侧永远至少留 48 像素可以被点到（保证你任何时候都能关掉它）。
   - 窗口变窄时抽屉会自动收窄，不会跑出屏幕。

### 4.7 铺满全屏（双击标题）

1. **点哪里**：**双击抽屉顶部的标题文字**。
2. **看到什么**：抽屉瞬间铺满整个窗口，左侧页面被完全盖住。
3. 想还原：**再双击一次标题**，或者在抽屉里按 Esc（焦点不在视频区时）、点 ×。

> 全屏只是"这次看"，不会改变你记住的宽度，下次打开还是你拖出来的宽度。

### 4.8 在新标签页打开

**点哪里**：抽屉顶部的 **↗** 按钮。
**看到什么**：浏览器新开一个标签页，就是这个视频的正常页面。
**用在哪**：想收藏、想发弹幕、想投币、想边看边操作别的页面时。

### 4.9 复制视频链接

**点哪里**：抽屉顶部的**复制链接**按钮（两个小方块的图标）。
**看到什么**：抽屉底部中间弹出一个小黑条「**链接已复制**」，约 1.6 秒后消失 —— 此时地址已经复制好，随便粘贴到聊天窗口即可。

如果弹出的是「复制失败，可点「在新标签打开」」：说明浏览器这次不允许写剪贴板，请用 ↗ 打开后再从地址栏复制。

### 4.10 焦点、Esc 与键盘

- 抽屉刚打开时，键盘焦点在抽屉上，**这时按 Esc 一定可以关闭**。
- 一旦你**点进了抽屉里的视频画面或评论区**，键盘焦点就进入了视频页面，此时顶层收不到 Esc —— **这是浏览器的安全边界，扩展无法绕过**。这种情况下请用 **×** 或点左侧遮罩关闭。
- 关闭抽屉后，键盘焦点会**回到你点的那条链接**上，用 Tab 继续浏览不会"丢位置"。
- 关闭状态下，Tab 键**不会**钻进抽屉里（抽屉彻底离场时键盘不可达）。

### 4.11 加载失败怎么办

如果 8 秒内抽屉里一直是黑的，会出现一块深色提示：

- 大字：**「页面未能加载」**
- 小字：说明可能是网络较慢，或这个页面不允许被放在别的页面里
- 两个按钮：**「重试」** 和 **「在新标签打开」**

**点哪里 → 看到什么**：

- 点「重试」→ 抽屉重新加载同一个视频（适合网络抖动）。
- 点「在新标签打开」→ 新标签页正常打开视频（适合"就是不让我嵌"的情况）。

另外，如果视频页本身报错（比如被删除、需要登录），抽屉里会显示 B 站自己的错误页，这是正常现象。

### 4.12 地址栏后面多出来的 `#sidepeek=...` 是什么

抽屉打开时，地址栏末尾会多一段类似 `#sidepeek=https%3A%2F%2Fwww.bilibili.com%2Fvideo%2FBV...` 的内容。

- **这是正常的**，是 SidePeek 用来让"后退=关抽屉、前进=重开抽屉"生效的记账标记。
- 关掉抽屉后，这段会自动消失。
- 如果你在抽屉打开时刷新了页面（F5），SidePeek 会自动把这段清理掉，不会让你的地址栏一直挂着脏尾巴。

## 5. 常见问题 FAQ

### 1. 为什么我点视频没反应？

按下面顺序自查：

1. **是不是 B 站页面？** 扩展只在 `bilibili.com` 生效，其他网站点了不会有任何变化。
2. **是不是视频链接？** 动态、专栏、用户主页、番剧索引页、直播页等不是视频页，会正常跳转。
3. **装完扩展后刷新页面了吗？** 安装前就开着的 B 站标签页需要按一次 `F5`。
4. **扩展还开着吗？** 打开 `chrome://extensions`，确认 SidePeek 卡片存在且开关是开的（如果是灰的，点一下打开）。
5. **是不是按住了 Ctrl/⌘/Shift/Alt，或用中键点的？** 这些组合按设计**不拦截**，会用浏览器默认方式开新标签。

### 2. 为什么我点了，整个页面直接跳走了，没弹抽屉？

常见原因（都在设计之内）：

- 你点的是**非视频**页面；
- 你点的是**当前正在看的这个视频**；
- 当前页面正在**全屏播放**（按过播放器的全屏键）—— 这时抽屉显示不出来，所以不接管，按正常方式跳转；**退出全屏再点**就有抽屉了；
- 你点的是卡片上的**小按钮**（"稍后再看"、点赞等），按钮会正常响应，不弹抽屉；
- 你按住 Ctrl 等修饰键，或者用中键点了。

### 3. 为什么按 Esc 关不掉抽屉？

因为你刚才**点进了抽屉里的视频画面或评论区**，键盘焦点已经进了抽屉内部的页面，顶层收不到 Esc。

**解决办法**：用右上角 **×** 关闭，或者点抽屉左侧那块变暗的区域。扩展无法跨文档捕获按键，这是浏览器的安全边界，不是 bug。

### 4. 为什么宽度用键盘调不了？

v0.1.0 的调宽只支持**鼠标拖动抽屉左边缘**。键盘调宽（无障碍拖拽条）还没做，已列入已知限制，会在后续版本考虑。

### 5. 为什么宽度记不住？

- 宽度是在你**拖动并松手**的那一刻才保存的，只是把鼠标移过去不算。
- 宽度记在**本机**、只有一份：换电脑、换浏览器用户、无痕窗口里都不会跟着走。
- 清理浏览器数据 / 卸载扩展会把这条记录一起清掉。
- 如果窗口特别窄，你拖出来的宽度可能会被自动收窄（保证抽屉不出屏、左侧留出可点的关闭区域），看起来像"没记住"。

### 6. 为什么抽屉里的视频不自动播放？

浏览器对"自动播放带声音的视频"有统一限制，和 SidePeek 无关。在抽屉里点一下播放键即可。

### 7. 为什么抽屉里提示未登录 / 不能发弹幕、评论、投币？

抽屉里是真正的 B 站页面，能不能发东西由 B 站根据你的登录状态判断。如果抽屉里操作不顺畅（尤其从搜索页等不同站点打开时），点右上角 **↗** 在新标签页里操作最稳。

### 8. 关掉抽屉后，视频还在响？

- 关掉抽屉后约 0.4 秒内声音会停止（SidePeek 会把抽屉里的页面彻底关掉）。
- 如果还在响，多半是**左边原页面的视频**在播 —— SidePeek 不会替你暂停原页面（这是刻意的，避免打断你正在看的内容），请自己点暂停。

### 9. 抽屉打开时，原来那页的视频还在播，正常吗？

正常。SidePeek 不会主动暂停原页面视频（刻意设计）。你可以自己暂停，两个视频互不影响。

### 10. 为什么有时候"后退"要按两次才关掉抽屉？

如果你在抽屉里**继续点了别的视频**（抽屉内部翻过页），浏览器会为这些翻页记几条内部历史，这是浏览器的行为，扩展无法阻止。

- 只开过一次、没在抽屉里翻页时，后退**按一次**就关；
- 关抽屉本身**永远是一次点击**（×、Esc、遮罩）；只有用浏览器后退键时才可能遇到这个现象。

### 11. 地址栏后面的 `#sidepeek=...` 是病毒吗？

不是。这是 SidePeek 的记账标记，用来让"后退=关抽屉、前进=重开抽屉"天然成立。关掉抽屉就消失，刷新页面也会自动清理。

### 12. 点工具栏上的 SidePeek 图标没反应？

正常。v0.1.0 **没有弹窗界面**，图标只是一个"扩展已安装"的标识与固定的入口位。所有功能都在 B 站页面里直接用，不需要点图标。

### 13. 能在别的网站用吗（YouTube、知乎、微博……）？

不能。v0.1.0 只支持 `bilibili.com` 及其子域名（如 `search.bilibili.com`）。其他网站点击视频链接不会有任何变化，也不会报错。

### 14. 手机上能用吗？

不能。这是电脑版 Chrome 的扩展。手机浏览器通常不支持安装扩展；手机版 B 站（`m.bilibili.com`）也不在支持范围内。

### 15. 为什么在抽屉里点别的视频，不会再弹出一层抽屉？

刻意设计。如果抽屉里再弹抽屉，屏幕上会堆起一堆层，越点越乱。所以抽屉内部点视频 = 在抽屉内部换页，符合"看完了继续看相关推荐"的直觉。

### 16. 为什么某个视频在抽屉里打不开 / 一直黑屏？

- 等 8 秒会出现「页面未能加载」提示，点「重试」；仍然不行就点「在新标签打开」。
- 有些页面（例如需要特殊权限、地区限制、或 B 站临时故障）可能无法嵌在抽屉里 —— 这时用新标签页打开最稳。
- 网络慢时加载时间会超过 8 秒，也会出现这条提示，重试通常就好。

### 17. 装了它，B 站会知道我用了扩展吗？会收集我的数据吗？

SidePeek：

- **不收集**任何用户数据，**不上传**任何统计或日志；
- **不发送**任何内容到第三方服务器；
- 只会做一件事需要联网：当你点开某个视频时，扩展会向**哔哩哔哩自己的服务器**请求一下这个视频页的标题（就是你正在看的那个页面），用来把抽屉顶部的标题显示正确；
- 在本机只保存**一个数字**：你拖动后的抽屉宽度。

### 18. 我只想用一会儿，怎么彻底卸载干净？

见下一节。

### 19. 用 Edge、QQ 浏览器、其他国产浏览器行吗？

v0.1.0 **只在 Chrome 上验证过**。同内核浏览器（如 Edge、Brave）理论上也能用同样的"加载已解压扩展"方式安装，但未做测试，不保证效果。

### 20. 为什么我明明在 B 站，点视频还是没反应？

请回看第 1 条自查清单。如果全部排除（是 B 站、是视频链接、已刷新、扩展已启用、没用修饰键），那就是 **B 站改版导致失效**的可能（已知限制第 11 条），请到项目 Issues 反馈，附上页面地址与截图。

## 6. 卸载与清理

### 卸载扩展

1. 地址栏输入 `chrome://extensions` 回车；
2. 找到 **SidePeek** 卡片；
3. 点卡片上的 **「移除」**，弹窗里点确认；
4. 列表里卡片消失即已卸载。

如果你还想把文件也删干净：卸载后，把当初解压出来的那个文件夹（`SidePeek-main`，或你 `git clone` 得到的 `SidePeek`）删掉即可（**先卸载再删文件夹**，否则扩展会变成报错状态）。

### 会留下什么数据

只有一条：**你拖动保存的抽屉宽度**（一个数字，存在本机浏览器里）。

- 点「移除」时，Chrome 会连同这条记录一起清除，不需要额外操作。
- SidePeek 不修改 B 站的任何设置、不写入 B 站账号、不留常驻后台进程。它在每个 B 站页面里只装一个**被动的点击监听**：你不点视频，它什么也不做；关掉浏览器或卸载后，不会再有 SidePeek 的任何行为。

## 7. 已知限制

以下是 **v0.1.0 明确不做 / 做不到**的事情，写在这里是为了不让你觉得"是不是坏了"：

1. **只在哔哩哔哩域名生效**（`*.bilibili.com`）。其他网站点击视频链接没有任何变化。
2. **抽屉里不能再弹出抽屉**：在抽屉里点别的视频，是在抽屉内部换页（刻意设计，避免层层套娃）。
3. **Esc 在焦点进入视频区域后失效**：点到播放器/评论区后，键盘焦点进了抽屉里的页面，顶层收不到 Esc；请用右上角 × 或点遮罩关闭。
4. **抽屉固定深色皮肤**，不跟随系统的亮色/暗色模式（v0.1 有意为之）。
5. **需要 Chrome 102 及以上**版本。
6. **宽度只能用鼠标拖动左边缘调整**，暂不支持键盘调宽。
7. **连点去抖未实现**：极短时间内连续点多个视频，可能看到几次加载闪烁；正常速度点击不受影响。
8. **抽屉内翻过页后可能出现"后退要按两次"**：在抽屉里继续点视频会让浏览器历史增加子记录，这是浏览器自身行为；关闭抽屉本身仍是一次点击即可。
9. **不申请标签页权限**：扩展无法自动操作/切换标签页；「在新标签页打开」按钮只是打开链接。
10. **视频不会自动播放**：受浏览器自动播放策略限制，需要在抽屉里点一下播放。
11. **B 站改版可能导致失效**：页面结构变化后，链接拦截或加载可能失灵，届时需要更新扩展。
12. **非官方工具**，与哔哩哔哩无任何关联；不收集任何用户数据，不发送任何统计。
